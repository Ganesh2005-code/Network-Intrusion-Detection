About Network Intrusion Detection System

Project: Network Intrusion Detection System

Algorithm: Random Forest

Dataset: NSL-KDD

Total Features: 41

Training Samples: 100,778

Testing Samples: 25,195

Accuracy: 99.92%

This project detects malicious and normal network traffic using a Machine Learning based Random Forest model. It also includes CSV upload, prediction history, ROC Curve, Confusion Matrix and Self-Replication Network Simulation.
